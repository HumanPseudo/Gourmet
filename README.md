# gourmet

POS system for restaurant management.

**Features:** menu management, restaurant tables, order workflow (open → close), kitchen
display, inventory tracking (items, recipes, movements), jukebox queue with remote
player, role-based staff accounts, token-authenticated REST API.

**Stack:** Django + Ninja API, PostgreSQL, Tailwind CSS, HTMX, Docker.

## Requirements

- Docker

## Installation

Build the project:

```bash
make init
```

## Usage

### Run the project

```bash
make run
```

Open http://localhost:8000/.

### Admin access

```bash
# Create superuser (admin@example.com / admin)
docker compose run --rm app python manage.py ensure_superuser

# Or seed demo data (roles, users, tables, menu items)
docker compose run --rm app python manage.py seed
```

Access http://localhost:8000/gourmet-admin/.

### Running commands

To run Django commands like migrations and shell or to enter the container bash do:

```bash
docker compose run --rm app bash
docker compose run --rm app python manage.py createsuperuser
docker compose run --rm app python manage.py migrate
docker compose run --rm app python manage.py shell
```

### Stop containers

To stop containers run:

```bash
docker compose down
```

### Update project

To rebuild the project after adding or updating requirements:

```bash
docker compose build
```
